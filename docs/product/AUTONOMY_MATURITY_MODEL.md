# Autonomy Maturity Model — Product Vision

This document is descriptive future context, not V1 scope.

- N1: manual operator service; optional assistive tools.
- N2: AI copilot; operator chooses final outbound content.
- N3: category-governed autonomy; some categories autonomous, others require HITL.
- N4: broad eligible-category autonomy with HOTL/veto supervision.

Institution/supervisor raises durable maturity only through human governance and evidence. Future system safety controls may lower autonomy automatically, never raise it automatically.

The current V1 implements N1 and N2 only.
